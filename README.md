# FractionFlow

A Next.js app for FractionFlow — a round-up savings and giving concept. Every
purchase leaves a fraction of change behind; FractionFlow catches it, sweeps
it into a wallet, and lets you decide (or auto-decide) how much gets invested
versus donated.

The page is a fully interactive prototype: tap **Spend something** to
simulate a purchase, watch the round-up get caught and swept into the
wallet, then switch to **Grow & Give** to split the balance between
investing and donating.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.

## Build

```bash
npm run build
npm run start
```

## Deploy on Vercel

This is a zero-config Next.js app. Import this repository in
[Vercel](https://vercel.com/new) and it will build and deploy automatically
on every push — no environment variables or extra configuration required.
